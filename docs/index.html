05 / Scope matters

A review aid, not a green light.

Does this execute the project?

No. The scanner reads supported config files and bounded literal local shell references. It does not run package scripts, code hooks or MCP servers.

Does zero findings mean safe?

No. Dynamic paths, nested scripts, language import/build execution and other surfaces are outside the current scope. A report cannot certify repository safety.

Is this malware detection?

No. Severity is a heuristic review priority. Legitimate automatic tasks can be flagged high; reported findings are not evidence of compromise.

Can I contribute a missed case?

Yes. Inert and redacted minimal examples are welcome. Please don't submit live malicious payloads, credentials or private code.
